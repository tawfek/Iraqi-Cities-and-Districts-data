هذا المستودع يوفر بيانات JSON مفتوحة للمحافظات العراقية والأقضية والنواحي التابعة لها، مع معرفات ثابتة مناسبة لنماذج العناوين، وتكاملات التوصيل، والبحث الجغرافي. الأسماء المعروضة محفوظة باللغة العربية كما وردت في البيانات.

ملف cities.json هو سجل المحافظات. لكل سجل ملف أقضية يطابق اسمه قيمة id-key، مثل 1-NJF.json.

قواعد العلاقة بين الملفات

  1. قيمة state_id في كل قضاء تساوي id للمحافظة.
  2. بادئة وامتداد اسم ملف المحافظة يطابقان id وkey.
  3. معرفات الأقضية فريدة على مستوى مجموعة البيانات.
  4. الملفات JSON بترميز UTF-8 وبمصفوفة في المستوى الأعلى.

قائمة ملفات البيانات

geoBoundaries-IRQ-ADM1_simplified.geojson يحتوي حدود المحافظات بصيغة GeoJSON. يستخدم التطبيق properties.shapeISO، مثل IQ-KA، لربط الشكل بالمحافظة في cities.json. الملف يحدد الحدود فقط ولا يضيف إحداثيات داخل سجلات المدن أو الأقضية.

بنية سجل المحافظة

الحقلالنوعالوصف
idintegerمعرف المحافظة
namestringالاسم العربي
keystringرمز لاتيني من 3 أحرف
iso_codestringرمز ISO، مثل IQ-NA
country_idintegerمعرف الدولة
ebhar_idUUIDمعرف تكامل Ebhar
alwaseet_idintegerمعرف تكامل Alwaseet

بنية سجل القضاء

الحقلالنوعالوصف
idintegerمعرف القضاء
namestringاسم القضاء أو الناحية
state_idintegerمرجع المحافظة
is_prime_supportedbooleanحالة دعم Prime
prime_idintegerمعرف Prime
ebhar_idUUID/nullمعرف Ebhar الاختياري

أمثلة الاستخدام

لا تحتاج أمثلة Node.js وPython إلى حزم خارجية. شغّلها من جذر المشروع.

const cities = require('./data/cities.json');

read.py
123456
import json
from pathlib import Path

root = Path('data')
cities = json.loads((root / 'cities.json').read_text(encoding='utf-8'))
najaf = next(city for city in cities if city['key'] == 'NJF')
فحص صحة البيانات: npm run validate أو node scripts/validate.js

ملاحظات مهمة

  • استخدم id وkey كمعرفات مستقرة، ولا تعتمد على الاسم العربي كمفتاح فريد.
  • قد تكون قيمة ebhar_id فارغة null، وهذا يعني أن الربط الاختياري غير متوفر.
  • البيانات لا تدعي مصدراً رسمياً أو ضماناً للاكتمال أو جدول تحديث ثابت.
